### Ключевые идеи для перехода от стейта к URL-параметрам

1. **Что должно жить в URL**
   - Фильтры списка клиентов: `query`, `parentId`, `regionId`, `partyType`.
   - Пагинация: `limit`, `offset`.
   - Сортировка: `sortBy`, `sortOrder`.
   - Критерий: если состояние влияет на запросы, должно переживать refresh и шариться ссылкой — это кандидат в URL.

2. **Single Source of Truth**
   - Эти параметры **не дублируются** в глобальном `useState`.
   - Источник истины: только URL (`searchParams`).
   - Компоненты (`ClientsPage`, `ClientsFilters`, `ClientsTable`) получают уже собранный объект `ClientsFilters` и вызывают коллбеки `updateFilters`/`onFiltersChange`, которые под капотом меняют URL.

3. **Схема работы с URL**
   - При чтении:
     - `URLSearchParams` → маппинг в `ClientsFilters` с учётом:
       - дефолтов (`limit`, `offset`, `sortBy`, `sortOrder`),
       - приведения типов (числа, enum).
   - При записи:
     - собрать новый `URLSearchParams` из `ClientsFilters`,
     - обновить URL через `history.replaceState` (или `useSearchParams` в `react-router-dom`) без перезагрузки страницы.
   - Опционально не писать в URL параметры, равные дефолтам / пустые.

4. **Роли разных видов стейта**
   - **URL state**: фильтры, сортировка, пагинация.
   - **Server state**: данные списка клиентов (React Query), зависят от `ClientsFilters`.
   - **UI state** (может остаться в `useState`):
     - модалки, snackbar, выбранный клиент,
     - временный `localQuery` с debounce (чтобы не обновлять URL на каждый символ).

5. **UX-нюансы**
   - Для поля поиска полезно иметь:
     - локальный `localQuery` (что вводит пользователь),
     - дебаунс → по истечении задержки записывать в URL (и дергать запрос).
   - Остальные фильтры (селекты, пагинация, сортировка) можно сразу писать в URL по изменению.

6. **Цель в тестовом задании**
   - Показать:
     - понимание разделения URL/server/UI стейта,
     - умение сделать URL единственным источником правды для фильтров,
     - аккуратный, простой маппинг `URL ↔ ClientsFilters` без лишних локальных состояний.
