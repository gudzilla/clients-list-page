# Clients Management App

Тестовое задание: Front-end приложение для управления списком клиентов.

## 🚀 Запуск проекта

### 1. Бэкенд (FastAPI)

Приложение требует запущенного API.

```bash
# Перейдите в папку бэкенда
cd backend

# Активируйте виртуальное окружение (если используется)
# source .venv/bin/activate  # macOS/Linux
# .venv\Scripts\activate     # Windows

# Установите зависимости (если еще не установлены)
pip install -r requirements.txt

# Запустите сервер
uvicorn src.main:app --reload
```
API будет доступно по адресу: `http://localhost:8000`

### 2. Фронтенд (React)

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev
```
Приложение откроется на: `http://localhost:5173`

## ✅ Реализованный функционал

### Список и Фильтрация
- [x] **Таблица клиентов**: Отображение данных с server-side пагинацией и сортировкой.
- [x] **Поиск (Query)**: Текстовый поиск с `debounce` (300ms) для снижения нагрузки на сервер.
- [x] **Селекты фильтров**:
    - **Родительский клиент**: Динамическая подгрузка списка при открытии (запрос к API).
    - **Регион**: Кэшируемый список (загружается один раз, далее берется из кэша).
    - **Тип стороны**: Статичный список (Физ. лицо / Юр. лицо).
- [x] **Синхронизация с URL**: При перезагрузке страницы состояние фильтров сохраняется.

### CRUD Операции
- [x] **Создание**: Модальное окно с валидацией полей (React Hook Form + Zod).
- [x] **Редактирование**: Предзаполнение формы данными выбранного клиента.
- [x] **Удаление**: Удаление клиента с диалогом подтверждения.

### Валидация
- Обязательные поля (Название, Тип стороны).
- Валидация формата данных (максимальная длина).
- Обработка ошибок от API (например, дубликаты клиентов).

## 🛠 Технический стек

- **Core**: React 19, TypeScript, Vite
- **UI Kit**: Material UI (MUI) v7
- **State Management & Data Fetching**:
    - **TanStack Query v5** (серверное состояние, кэширование)
    - **React Hooks** (локальное состояние)
- **Forms**: React Hook Form + Zod Resolver
- **Routing/URL**: Кастомный хук для синхронизации стейта с URL Search Params.

## 📂 Структура проекта

Реализована Feature-Sliced архитектура (упрощенная):

```
src/
├── features/clients/      # Основная фича "Клиенты"
│   ├── components/        # UI компоненты (Таблица, Фильтры, Формы)
│   ├── pages/             # Страница раздела
│   ├── services/          # API запросы (React Query hooks)
│   └── types/             # TypeScript интерфейсы
├── api/                   # Настройка Axios клиента
├── hooks/                 # Общие хуки (useDebounce)
└── utils/                 # Утилиты (парсинг URL)
```
